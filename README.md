# Java Learning Projects

This repository contains exercises and projects completed as part of my 
"Development of Software Solutions" course, where I'm learning Java programming 
from the ground up.

## What's inside

Simple programs and mini-projects covering core programming concepts such as:
- Variables, loops, and conditionals
- Object-oriented programming basics (classes, objects, inheritance)
- Working with collections and data structures
- Basic problem-solving exercises

## Why this repo

Created as a way to practice and track my progress while building a solid 
foundation in Java — one of the most widely used programming languages in 
software development.
